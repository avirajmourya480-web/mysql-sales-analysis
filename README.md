# E-Commerce Sales Analysis using SQL

## Project Overview

This beginner-friendly SQL project analyzes an e-commerce sales database using MySQL.

The project demonstrates how SQL can be used to:
- Store structured business data
- Join related tables
- Calculate revenue
- Analyze customers and products
- Group and aggregate sales
- Rank products
- Analyze monthly and category-level performance

## Database Structure

### Customers
Stores customer information such as name, city, and state.

### Products
Stores product names, categories, and prices.

### Sales
Stores transactions and connects customers with products.

## Project Questions

The queries answer questions such as:

1. What is the total revenue?
2. Which products generate the most revenue?
3. Which products sell the most units?
4. Which category generates the most revenue?
5. Which customers spend the most?
6. What is the monthly revenue?
7. What is the average order value?
8. Which cities generate the most revenue?
9. How can products be ranked by revenue?

## How to Run

1. Install MySQL.
2. Open MySQL Workbench or another MySQL client.
3. Run `database.sql`.
4. Run `queries.sql`.
5. Explore the results.
